## 整体结构推测

把上面拼起来，这套料大致能搭出一个**能移动、能看、能听、能说、能联网**的桌面小机器人：

- **大脑**：ESP32-S3（MicroPython）
- **看**：OV3660 摄像头（经 FPC 排线装到 SG90 云台上，可转头）
- **听 / 说**：INMP441 麦克风 + MAX98357 + 扬声器
- **动**：MiniQ 底盘（2 电机）+ SG90 二自由度云台（2 舵机），PWM 全由 PCA9685 统一驱动，DRV8833 负责电机功率输出
- **联网**：ML307R Cat.1 4G 模块（脱离 WiFi 也能上网）
- **供电**：3.7V 锂电池 → DCDC 升 5V
- **存储**：2GB TF 卡 + SD 卡模块
- **结构 / 工具**：亚克力 + 铜柱 + 焊接/加工工具

> 屏幕（1.54 寸 ST7789）暂不接入本期方案（节省引脚），仍保留备用。

## 建议留意 / 可能还需要补的

1. **FPC 排线方向**：排线是「反向 / 金手指异面」，接 OV3660 与开发板前先确认两端金手指朝向匹配，插反可能识别不到摄像头。
2. **SD 卡模块供电**：若模块带 AMS1117 稳压芯片，VCC 接 5V；极简款（无稳压）接 3.3V。
3. **接插件 / 线材**：电池到 DCDC、DCDC 到各模块的供电线、开关，按需补。
4. **SIM / 物联网卡激活**：自带套餐 ≠ 即插即用，确认卡已激活 / 实名（问卖家或扫码激活）。
5. **摄像头真实引脚**：向卖家要 `camera.init` 示例代码，用于定稿引脚分配表。
