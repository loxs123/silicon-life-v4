## SD 卡（外接 SPI 卡模块，替代板载 TF 槽）

> ⚠️ 板载 TF 槽走 3 线 SDIO（CMD=GPIO38 / CLK=GPIO39 / DAT0=GPIO40），**没引出 CS**；当前 cam+st7789 固件的 `machine.SDCard` 又不接受自定义 SDMMC 引脚（默认脚一挂就 `OSError 16` EBUSY）。所以**板载槽在此固件下用不了**。
> 改用「外接 SPI SD 卡模块」（自带 CS 片选脚），配纯 Python 驱动 `sdcard.py` 走 SPI 模式即可，**无需重刷固件**。板载 TF 槽**空着别插卡**（避免和外接模块抢同一组线）。

| 本件引脚 | 连到部件 | 对方引脚 | 风险 |
|---|---|---|---|
| SCK / CLK | ESP32 | GPIO39 | 复用板载 SD_CLK 线 |
| MOSI / DI | ESP32 | GPIO38 | 复用板载 SD_CMD 线 |
| MISO / DO | ESP32 | GPIO40 | 复用板载 SD_DATA 线 |
| CS | ESP32 | GPIO45 | 空闲脚做片选。⚠️ 别用 GPIO0：它是 BOOT 启动脚(复位时被采样)，做 CS 有进下载模式的风险。GPIO45 安全：CS 是高阻输入，复位时不影响启动，只在开机后做输出 |
| VCC | 电源 | 3V3 或 5V | ⚠️ 看模块标注：裸 microSD 转接板接 **3V3**；带稳压+电平转换的(蓝板)接 **5V** |
| GND | 公共 GND | — | 必须共地 |

软件（先上传 `sdcard.py` 到板子）：
```python
import sdcard, os
from machine import SoftSPI, Pin
sd = sdcard.SDCard(SoftSPI(-1, sck=Pin(39), mosi=Pin(38), miso=Pin(40)), Pin(45))
os.mount(sd, "/sd")
```

## ESP32-S3-CAM（主控，所有用到的脚）

| 本件引脚 | 连到部件 | 对方引脚 | 风险 |
|---|---|---|---|
| GPIO47 | PCA9685 | SDA | — |
| GPIO48 | PCA9685 | SCL | ⚠️ 也是板载 RGB 灯(WS2812)数据脚：USB 供电时 RGB 会乱闪，不影响 I2C |
| GPIO42 | MAX98357 | BCLK | — |
| GPIO41 | MAX98357 | LRC | — |
| GPIO21 | MAX98357 | DIN | — |
| GPIO14 | INMP441 | SCK | — |
| GPIO1 | INMP441 | WS | — |
| GPIO2 | INMP441 | SD（麦数据） | — |
| GPIO43 | 屏 ST7789 | SCL/SCK | ⚠️ 占 TTL-USB 口，烧录改走 OTG 口 |
| GPIO44 | 屏 ST7789 | SDA/MOSI | ⚠️ 占 TTL-USB 口 |
| GPIO3 | 屏 ST7789 | CS | ⚠️ strapping + 板载 RGB 灯，别加上下拉 |
| GPIO46 | 屏 ST7789 | DC | ⚠️ strapping 脚，别加上下拉 |
| GPIO4–18（除14） | 摄像头 OV3660 | FPC 座（板内已连） | 不接线；这些脚勿挪作他用 |
| GPIO39/38/40 | 外接 SD 卡模块 | SCK(39)/MOSI(38)/MISO(40) | 复用板载 SD 线走 SPI；板载 TF 槽空着别插卡 |
| GPIO45 | 外接 SD 卡模块 | CS（片选） | strapping 脚但安全(只在开机后做输出)；⚠️ 别用 GPIO0(BOOT 启动脚，做 CS 有进下载模式风险) |
| 5V 脚 | DCDC 模块 | 5V 输出（或 Type-C 5V） | 电池与 USB 别同时接，会倒灌打架 |
| 3V3 脚 | PCA9685 / INMP441 / 屏 等 | 各 VCC/VDD/RST/BLK | 输出脚，别外接电源；喂板子用 5V |
| GND | 公共 GND | — | 所有器件必须共地 |
| OTG USB-C 口 | 电脑 | USB 线（烧录 / REPL） | 烧录时拔电池；TTL 口被屏占用，用不了 |
| GPIO0 | —（BOOT 键，空闲） | — | strapping，本方案没用 |
| GPIO48 | （板载 RGB 灯 WS2812） | DI，VDD 取自 USB_5V | 已兼作 I2C SCL；只在 USB 供电时亮，电池供电时不亮 |
