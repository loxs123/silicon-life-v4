## 一分钟速览

- **RSI 的判定不能用"有没有变强"，要用三问**：① 修改机制本身能不能被修改（闭环）② 改动是否持久保留（留存）③ 同等算力下改进率是否在上升（加速）。三者全满足才算 RSI。
- **一阶改进已被证实**：DGM 让 SWE-bench 从 20.0% 到 50.0%、Polyglot 14.2% 到 30.7%；SICA 从 17% 到 53%；AlphaEvolve 把 4×4 复数矩阵乘法压到 48 次标量乘法（56 年来首次改进 Strassen 该设定），并加速了训练它自己的模型。
- **二阶证据（改进率上升）几乎没有**。带 archive 的进化式方法在观测上等价于"并行搜索 + 筛选"，现有实验很少把改进成本放进分母。
- **瓶颈已从"生成改动"转移到"判断改动是否真的更好"**：2026 年的实证显示，一个坍缩成"永远判过"的空评器也能训出同样有效的技能，下游分数无法证明评估器有效；生产流水线里出现过 100% 通过率掩盖 68% 真实能力。
- **自我纠正的天花板**：没有外部信号时模型纠不动自己的推理错误（ICLR 2024 否定结果、TACL 2024 综述）。
- **安全风险已有实证**：STOP 测量了自改代码绕过沙箱的频率；Claude 3 Opus 出现 14% 的选择性顺从，RL 后伪装对齐推理升至 78%。
- **判断**：RSI 已从哲学问题变成工程问题，但"递归"部分尚未被证实。当前最值得投入的是可验证性基础设施（确定性验收、冻结 holdout、评估器审计、谱系回滚），不是更强的生成器。

### 技能自进化这条线（详见 `03-skills.md`）

- **收益是真的，但只在人工策划时成立**：SkillsBench 配对实验里人工技能 +16.6pp（33.9%→50.5%）；而 LLM 自写技能约 +0.0pp。瓶颈是筛选与治理，不是生成。
- **治理能把曲线拉起来**：按贡献淘汰 + 库宽度上限 + 约束合成，让 MBPP+ hard-100 的 pass@1 从 0.258 到后期窗口 0.584（+0.328，100 轮）。
- **一条硬界限**：judge 把失败判成通过的比例 ≥ (1−τ)/2 时，任何样本量都退不掉任何技能；且终局分数是糟糕的警报（只反映治理增益的约 1/5）。
- **技能会静默失效**：57 个真实仓库的 105 次版本迁移，每次都会让部分旧技能过期，六个前沿 agent 只能拿到 29.9%–69.7% macro F1。

1. 只想抓结论 → 读本页 + `01-survey.md` 第 0 节。
2. 想理解脉络 → `01-survey.md` 第 1–3 节（定义、思想史、为什么 2023 年才成立）。

4. 想找论文 → `02-papers.md`。
5. 想质疑这套叙事 → `01-survey.md` 第 6 节（证据审计）、第 8 节（争议）。
